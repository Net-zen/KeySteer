## 操作步骤与默认按键

进入时会激活并锁定鼠标下的窗口。之后鼠标移开，也不会自动换目标。屏幕上的数字表示窗口编号，输入编号即可激活目标并把鼠标移到它的中心。

| 按键 | Window 中的操作 |
| --- | --- |
| `H / J / K / L` | 向左 / 下 / 上 / 右移动；按住可连续调整 |
| `S` | 在移动与中心缩放之间切换 |
| `C` | 居中 |
| `D` | 移到下一块显示器 |
| `F` / `Shift+F` | 最大化／还原；最小化／还原 |
| 数字 | 按编号选择窗口 |
| `Tab / Shift+Tab` | 下一个 / 上一个窗口；在标签组内优先循环成员 |
| `X` | 请求关闭当前窗口；应用可能显示保存确认 |
| `Z / Shift+Z` | 撤销 / 重做窗口调整 |
| `Shift+C` | 恢复本次窗口会话初始的位置、尺寸及窗口状态 |

默认只列出**当前屏幕、非最小化**的候选窗口。已有编号尽量保持稳定，关闭窗口不会把其余窗口重新编号；重新进入时可能回收空缺编号。只有可能组成更长编号的前缀才等待，默认 250 ms。

需要点击一下应用？按住 `Primary` 临时使用 Normal 的鼠标移动、滚动和点击绑定，松开后继续调整原目标。Window 各模式的方向键独立配置，修改 Normal 的方向键不会自动修改这里的键位。

## 用网格快速移动

Window 的 Move 状态可以在上层激活真正的 Grid 或 Recursive Grid，底层仍锁定同一个窗口。默认 `G` 或 `Primary+G` 进入 Grid，`Primary+F` 进入 Recursive Grid；裸 `F` 保留最大化操作。

入口来自 Normal 的有效配置：编译时将指向这两个模式且不与 Window 绑定冲突的入口补入 Window；已有绑定（包括 `none`）优先。修改 Normal 的入口、别名或应用覆盖后会重新计算，临时 Normal 的入口也沿用其配置，不固定为 G/F。

上层完整沿用原模式的网格、Tab／Backspace 回退、Space 重置、跨屏路径保留及完成配置。网格实际移动鼠标时，窗口中心跟随定位点，边缘受目标屏幕工作区约束。退出到 Normal／Idle 或自然完成返回时回到 Window；`keep` 则继续定位。一轮定位共享一次窗口撤销记录。

## 音频控制

以下默认组合键在 Window、Quick 和 Editor 中可用。按住 `V` 再按对应键；系统操作额外按住 `Shift`。

| 操作范围 | 降低 / 提高音量 | 静音切换 | 上一个 / 下一个输出设备 |
| --- | --- | --- | --- |
| 当前目标窗口所属应用 | `V+J / V+K` | `V+M` | `V+H / V+L` |
| 系统 | `Shift+V+J / Shift+V+K` | `Shift+V+M` | `Shift+V+H / Shift+V+L` |

音量每次变化 1%；提高音量不会自动解除应用静音。同一应用的多个窗口可能共享音频会话。

- **Windows**：应用音量需要可用音频会话；没有会话时先让应用播放声音。切换设备后是否立即迁移当前声音取决于应用。
- **macOS**：系统音频支持 macOS 14+；应用独立音频需要 macOS 14.2+ 和系统音频录制权限，本地处理会增加音频延迟。某些输出设备不支持软件音量调节。

## 选择多个窗口

按 `Ctrl` 进入多选输入，帮助面板显示输入和快捷键，选中窗口实时显示边框，卡片应用名或 Tab 组标题前显示 `✓`，默认选中底色为柔和薄荷绿。选中卡片的底色、边框颜色和线宽可在 `[window.card]` 中配置，也可在网页配置工作室的「共用外观」中调整。第一段连续数字逐个选择，例如 `1234567` 表示编号 1～7；空格后的每段是完整编号，例如 `123 12 23` 表示 1、2、3、12、23。空格后的编号等到下一空格或确认才生效，输入 `12` 的途中不会误取消编号 1。重复输入已选编号会移除它。

直接按 `E`、`S`、`H/J/K/L` 等操作键，会自动提交当前编号并立即执行操作；不需要额外确认。也可按 `Ctrl` 或 `Enter` 只确认，`Esc` 撤销本轮输入。删除全部输入会恢复本轮编辑前的选择，并重新激活最初窗口。`Ctrl+X` 清空多选并恢复最初选中的窗口，不改变 `target = "active"` 等目标设置。

输入光标前的编号实时激活并显示在前台：`1234▏` 激活 4，退格成 `123▏` 激活 3，左移到 `12▏3` 激活 2。左右箭头或配置的编辑键移动输入光标，也可在中间插入、删除；选中集合仍由完整输入决定。多个逻辑窗口选中时，鼠标跟随它们已确认窗口中心的等权平均点，避免跨屏时叠加各窗口的相对偏移；初始进入和单选保留原有鼠标位置语义。

多选后的移动、按住方向键、`S` 切换后的缩放、居中、切屏、最大化、最小化、关闭和应用音频控制都作用于全部选中窗口。`E` 进入 Editor 时只平铺所选窗口，其余窗口保持原位；没有多选时仍自动平铺全局候选。选中 tab 组的任一成员即选中整个组；组内几何操作只执行一次，关闭和音频覆盖全部成员。同一进程的音频每次只调整一次。

`E` Editor 和 `T` Tab 保留各自的多选处理；`A` Quick、`R` Restore 进入和返回时均清空多选。Quick 仍按原有 `window_quick.target` 配置选取目标；未配置时沿用会话当前目标。

入口、确认和清空均可配置；`ctrl` 在 macOS 上仍表示 Control：

```toml
[window.bindings]
ctrl = "window_multi_select"
"ctrl+x" = "window_multi_clear"

[window.multi_select.bindings]
"ctrl enter" = "window_multi_confirm"
"primary+h" = "arrow_left"
"primary+l" = "arrow_right"
```

该表只在多选输入期间生效，编辑键显式配置在这里；支持左右箭头、Home/End、Backspace/Delete 及 Shift 方向选区。空格表示任一按键均可，`+` 表示组合键。
