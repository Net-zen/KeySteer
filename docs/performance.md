# 性能

**操作跟手，双屏识别也轻快。**

<PerformanceHighlights />

以下为 Windows 0.12.3 的实测结果。

## 响应速度

滚动、定位和分屏，典型响应约 **8–17 毫秒**。单窗口 400 个控件时约 **143 毫秒**出现首批标签；双 4K、800 个控件时，约 **225 毫秒**两屏都能看到第一批标签；看到目标就能输入选择。

<PerformanceLatency />

## 内存占用

启动待机约 **12 MiB**，日常操作后约 **16–19 MiB**，UI Hint 识别后约 **27–31 MiB**。识别时会短暂多用一些内存，图中也列出测试中记录到的最高占用。

内存按任务管理器默认显示的专用工作集统计；算上与系统共用的部分，启动时约 **38.1 MiB**。

## 测试说明

响应和内存分批统计，每组覆盖 8 个场景、120 次操作，每场景 3 个进程、每进程 5 次操作。UI Hint 采用 Hybrid 识别：单窗口 400 个控件，双屏各 400 个。

日常响应和内存采用此前完整场景重测的数据，UI Hint 响应采用修复后同场景 A/B 的复测结果。各进程启动后等待 3 秒再进行首次操作。

- **响应**：从按下测试按键到画面变化；鼠标移动看位置变化。不含实体键盘和显示器的额外延迟。
- **识别**：观察固定的首行标签区域，双屏取较慢的一屏；后续标签继续补全，不代表整轮识别已经完成。搜索和退出另算。
- **内存**：只算 KeySteer，不含其他程序和显存。最高占用是测试中采样记录到的最高值。
