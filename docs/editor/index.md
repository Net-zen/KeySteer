# 配置与模拟器(Beta)

先在浏览器里试改键，再用到桌面：可调整快捷键、鼠标速度、模式样式，也能用示例窗口练习分屏和分组。

从程序状态菜单选择 **Configuration & Simulator...**，会自动带入当前配置和已有工作区；也可以从下面打开后手动导入。

<p class="ks-open-simulator">
  <a href="../simulator" target="_blank" rel="noopener">打开配置与模拟器 ↗</a>
</p>

::: info 预览在本地，保存后再应用
数据只在本机浏览器处理，不会上传。网页操作只改变预览；下载配置或工作区文件并放回程序数据目录后，桌面程序才会使用它们。
:::

## 推荐用法

1. 导入现有 TOML，或从默认配置开始。
2. 修改键位和样式，边看预览边调整。
3. 下载 `keysteer.<名称>.toml`，放入 [KeySteer 数据目录](/reference/configuration#配置文件位置)。
4. 在状态菜单选择 **Reload Configuration**。

::: tip 配置报错时
运行 `keysteer --check -c <文件>` 查看原因。模拟器是预览工具，复杂动作、外部命令和平台权限仍以桌面程序为准。
:::

### 编辑布局和标签模板

从程序菜单打开时，已有 `workspace.ksw` 的预设会一起带入；也可点“导入工作区文件”。选择布局编号后编辑分区，`Ctrl+S` 修改备注；点“保存并下载工作区”会保存当前修改并保留其他预设。

将下载的 `workspace.ksw` 放回数据目录，随后按 `Alt+W → R` 重新读取，无需重启或重载 TOML。

完整写法见 [配置文件](/reference/configuration) 和 [模式与动作](/reference/modes-and-actions)。模拟器在新页面打开，放在副屏上也很方便。

## 可视化编辑窗口卡片

选择 Window 或 Quick、Editor、Restore、Tabs，在卡片编辑区调整：

| 要调整什么 | 操作方式 |
| --- | --- |
| 背景、编号、应用名、标题、边框 | 选择颜色和透明度 |
| 字体、字号、加粗、圆角和间距 | 直接修改，右侧实时预览 |
| 卡片位置 | 点选或拖动定位点、拖出范围、调整四边滑块，或选位置预设 |

修改会同步到预览和下载的 TOML，每项都可单独重置。实际运行时卡片仍会避让其他标记。
